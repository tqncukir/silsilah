Kunci Notifikasi

Khusus Admin Pusat. Dibuat sekali saja, sebelum notifikasi ke HP dinyalakan.

Cara memasang

  1. Tekan Buat kunci. Kunci dibuat di perangkat ini dan tidak dikirim ke mana pun.
  2. Buka Supabase → Edge Functions → Secrets, lalu tambahkan tiga rahasia di bawah (salin satu per satu).
  3. Kirim kunci publik saja ke Claude (aman). Kunci rahasia jangan dikirim ke siapa pun, termasuk Claude.

Kunci cukup dibuat sekali. Bila nanti diganti, semua jamaah harus menekan "Aktifkan pemberitahuan" lagi.

VAPID_PUBLIC kunci publik, boleh dikirim ke Claude

VAPID_PRIVATE kunci rahasia, JANGAN dikirim ke siapa pun

VAPID_SUBJECT alamat kontak pengirim

Kunci panggil (pengirim otomatis)

Supaya jadwal pagi/sore dan tugas langsung di database boleh memanggil pengirim notifikasi. Dibuat sekali, rahasia.

  1. Tekan Buat kunci panggil.
  2. Tambahkan rahasia NOTIF_PANGGIL di Edge Functions → Secrets.
  3. Salin perintah SQL, tempel di SQL Editor, lalu Run (menyimpan kunci yang sama di Vault).

NOTIF_PANGGIL rahasia, JANGAN dikirim ke siapa pun
